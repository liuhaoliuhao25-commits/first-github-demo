# 敏感词打码 — 使用说明

## 启动

双击桌面 **敏感词打码** 快捷方式，或直接运行 `敏感词打码.exe`。

## 界面

```
┌─────────────┬──────────────────────────────────┐
│ 🔍 敏感规则   │  📄 PDF批量打码 │ 🖼️ 图片批量打码  │
│             │                                  │
│ ☑ 手机号     │  [导入] [清空]      模式: [▼]    │
│ ☑ 身份证号   │  ┌─ 文件列表（可拖拽）─────────┐  │
│ ☑ 出生日期   │  │ ...                         │  │
│ ☑ 住址信息   │  └────────────────────────────┘  │
│             │  ┌─ 原始内容 ──┬─ 打码效果 ────┐  │
│ 🔑 自定义    │  │            │               │  │
│ [关键词输入] │  └────────────┴───────────────┘  │
│             │  输出目录: [________] [选择]       │
│ [清空][全选] │  [预览效果]    [🚀 批量导出]       │
└─────────────┴──────────────────────────────────┘
```

## 操作流程

1. 左侧勾选要打码的敏感类型（默认全选）
2. 可选：输入自定义关键词（一行一个）
3. 点击「📥 导入PDF/图片」或直接拖拽文件到列表
4. 选中文件 → 点击「预览效果」查看打码前后对比
5. 选择打码模式（黑块/模糊/星号）
6. 设置输出目录 → 点击「🚀 批量导出」

## 打码模式

| 模式 | 效果 |
|------|------|
| 纯黑块遮挡 | 敏感区域涂黑 |
| 高斯模糊 | 敏感区域模糊 |
| 星号*掩码 | 文字替换为 `***`（如 138****5678） |

## 注意

- 地址检测为模式匹配，建议配合自定义关键词
- 图片打码需安装 Tesseract OCR 才能精准检测文字
- PDF 黑块模式速度最快；模糊/星号模式需逐页渲染
