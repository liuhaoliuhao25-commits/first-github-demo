# AI 桌宠 - Windows 使用指南

## 系统要求

### 最低配置
- **操作系统**: Windows 10 64-bit (版本 1903 或更高)
- **处理器**: Intel Core i3 或同等 AMD 处理器
- **内存**: 4 GB RAM
- **磁盘空间**: 500 MB 可用空间
- **显卡**: 支持 WebGL 2.0 的显卡

### 推荐配置
- **操作系统**: Windows 11 64-bit
- **处理器**: Intel Core i5 或更高
- **内存**: 8 GB RAM
- **磁盘空间**: 1 GB 可用空间
- **显卡**: 支持 OpenGL 3.3 的独立显卡

## 安装方式

### 方式一：下载安装包（推荐）

1. **下载安装程序**
   - 访问 GitHub Release 页面：https://github.com/liuhaoliuhao25-commits/first-github-demo/releases
   - 下载最新的 `.exe` 安装文件
   - 文件名类似：`AI 桌宠-1.0.0-win-x64.exe`

2. **运行安装程序**
   ```
   双击 AI 桌宠 -1.0.0-win-x64.exe
   → 选择安装语言（中文）
   → 选择安装目录（默认：C:\Program Files\AI 桌宠）
   → 点击"安装"
   → 等待安装完成
   → 勾选"运行 AI 桌宠"
   → 点击"完成"
   ```

3. **首次启动**
   - 桌面上会出现"AI 桌宠"图标
   - 双击即可启动
   - 系统托盘（右下角）会出现宠物图标

---

### 方式二：开发者模式（需要 Node.js 环境）

1. **安装 Node.js**
   - 访问：https://nodejs.org/
   - 下载并安装 LTS 版本（推荐 18.x 或更高）
   - 验证安装：
     ```bash
     node --version
     npm --version
     ```

2. **克隆项目**
   ```bash
   git clone https://github.com/liuhaoliuhao25-commits/first-github-demo.git
   cd first-github-demo
   ```

3. **安装依赖**
   ```bash
   npm install
   ```

4. **启动开发模式**
   ```bash
   npm run electron:dev
   ```

5. **打包为安装包**
   ```bash
   npm run electron:build
   ```
   安装包会生成在 `release/` 目录

## 功能使用说明

### 基本操作

#### 1. 窗口控制
- **移动宠物**: 鼠标拖拽透明窗口
- **置顶/取消置顶**: 右键系统托盘图标 → 设置
- **最小化**: 点击窗口右下角 ➖ 按钮
- **关闭**: 点击窗口右下角 ✕ 按钮

#### 2. 系统托盘
右键点击任务栏右下角的宠物图标：
- 👁️ **显示/隐藏**: 切换宠物窗口可见性
- ⚙️ **设置**: 打开设置面板
- 🔄 **重启应用**: 重新启动应用
- ❌ **退出**: 完全退出应用

#### 3. 快捷键
```
Ctrl + H     显示/隐藏宠物窗口
Ctrl + S     打开设置面板
Ctrl + Q     退出应用
```
（快捷键可在设置中自定义）

---

### 设置面板

点击设置按钮（⚙️）打开设置面板：

#### 1. 常规设置
- **总是置顶**: 窗口始终显示在最上方
- **所有屏幕显示**: 多显示器模式下同时显示
- **开机自启动**: 系统启动时自动运行
- **检查更新**: 手动检查新版本

#### 2. AI 设置
- **语音回复**: AI 回复时自动播放语音
- **语音唤醒**: 通过语音唤醒 AI（需要麦克风）
- **Ollama 配置**: 本地 AI 服务地址和模型

#### 3. 语音设置
- **语音识别**: 启用麦克风录音
- **语音合成**: 启用 AI 语音播放
- **Whisper 模型**: 选择语音识别模型
- **Piper 模型**: 选择语音合成模型

#### 4. 外观设置
- **透明度**: 调节窗口透明度（20%-100%）
- **模型大小**: 调节 VRM 模型大小（50%-150%）

### AI 对话功能

#### 1. 配置本地 AI（Ollama）

1. **安装 Ollama**
   ```
   访问 https://ollama.ai/
   下载 Windows 安装包
   安装后自动运行
   ```

2. **下载模型**
   ```bash
   # 打开命令提示符
   ollama pull llama2
   
   # 或者使用其他模型
   ollama pull mistral
   ollama pull codellama
   ```

3. **在桌宠中配置**
   - 打开设置 → AI 设置
   - 确认 Ollama 端点：`http://localhost:11434`
   - 选择模型：`llama2`
   - 启用"自动启动"

#### 2. 与 AI 对话
- 目前通过代码调用 AI 接口
- 未来版本将添加对话输入界面
- AI 回复会自动显示在对话气泡中

---

### 语音功能

#### 1. 语音识别（Whisper.cpp）
1. 下载安装 Whisper.cpp
2. 下载中文语音识别模型
3. 在设置中配置模型路径
4. 点击麦克风图标开始录音
5. 点击停止进行识别

#### 2. 语音合成（Piper TTS）
1. 下载安装 Piper TTS
2. 下载中文语音模型
3. 在设置中配置模型路径
4. AI 回复时自动播放语音

## 常见问题

### Q1: 应用启动后看不到窗口？
**A:** 
- 检查系统托盘是否有图标
- 右键系统托盘图标 → 显示
- 按 `Ctrl + H` 快捷键
- 检查是否被其他窗口遮挡

### Q2: 窗口透明度过高？
**A:**
- 右键系统托盘 → 设置 → 外观
- 调整透明度滑块到 100%
- 或按 F5 刷新窗口

### Q3: AI 对话没有反应？
**A:**
- 确认 Ollama 已安装并运行：
  ```bash
  curl http://localhost:11434/api/tags
  ```
- 检查模型是否已下载：
  ```bash
  ollama list
  ```
- 在设置中确认 AI 配置正确

### Q4: 语音识别无法使用？
**A:**
- 检查麦克风权限设置
- 确认 Whisper.cpp 已正确安装
- 检查模型路径配置
- 尝试重新下载模型文件

### Q5: 应用占用内存过高？
**A:**
- 关闭不必要的动画效果
- 降低模型渲染质量
- 最小化宠物窗口
- 重启应用释放内存

### Q6: 全屏应用时宠物窗口不自动隐藏？
**A:**
- 这是正常设计，宠物会自动降低透明度
- 如需完全隐藏，右键系统托盘 → 隐藏
- 退出全屏后会自动恢复

### Q7: 开机自启动不生效？
**A:**
- 在设置中勾选"开机自启动"
- 检查 Windows 启动项是否被禁用
- 打开任务管理器 → 启动 → 启用 AI 桌宠

### Q8: 如何完全卸载？
**A:**
1. 运行卸载程序：
   ```
   控制面板 → 程序和功能 → AI 桌宠 → 卸载
   ```
2. 或删除安装目录：
   ```
   C:\Program Files\AI 桌宠\Uninstall.exe
   ```
3. 清理用户数据（可选）：
   ```
   C:\Users\你的用户名\AppData\Roaming\AI 桌宠\
   ```
