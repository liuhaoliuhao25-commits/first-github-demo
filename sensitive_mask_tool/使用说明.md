# 敏感信息打码工具 — 使用说明

## 简介

敏感信息打码工具是一款 Windows 桌面应用程序，用于对 PDF 文件和图片中的敏感信息进行批量打码处理。支持手机号、身份证号、出生日期、住址等常见敏感信息的自动识别，提供纯黑块遮挡、高斯模糊、星号掩码三种打码方案。

## 运行方式

1. 双击 `敏感信息打码工具.exe` 启动程序（无需安装 Python 或任何依赖）
2. 首次启动后，桌面会自动创建快捷方式，下次可从桌面双击快捷方式启动
3. 启动后显示主界面，包含左侧「敏感信息规则」面板和右侧两个标签页

## 界面说明

### 左侧：敏感信息规则面板（共用）

| 规则项 | 说明 |
|--------|------|
| 📱 手机号 | 匹配中国大陆 11 位手机号（如 13812345678） |
| 🪪 身份证号 | 匹配 18 位身份证号码 |
| 🎂 出生日期 | 匹配各种日期格式（1990年1月1日 / 1990-01-01 / 19900101） |
| 🏠 住址信息 | 匹配含省/市/区/路/街/号等关键词的地址文本 |
| 🔑 自定义关键词 | 手动输入敏感词，一行一个（如：张三、保密项目） |

> **重要：** 只对勾选的项目进行打码，未勾选的内容原样保留，不做任何处理。

### 右侧标签页

程序包含两个独立的标签页，各自配置互不影响：

#### 📄 PDF批量打码 标签页

- **导入PDF**：点击按钮选择 PDF 文件，或直接拖拽 PDF 文件到文件列表区域
- **文件列表**：显示已导入的 PDF 文件，支持 Ctrl/Shift 多选
- **打码模式**：下拉选择打码方案（独立于图片标签页的配置）
- **预览区**：选中文件后点击「预览打码效果」，左侧显示原始内容（首页），右侧显示打码后的效果
- **输出目录**：选择打码后文件的保存位置
- **批量导出**：一键处理所有导入的 PDF 文件

#### 🖼️ 图片批量打码 标签页

- 功能与 PDF 标签页类似，但针对 JPG、PNG、BMP、TIFF 等图片格式
- 支持拖拽导入图片文件
- 独立选择打码模式

## 三种打码模式

| 模式 | 效果 | 适用场景 |
|------|------|----------|
| 纯黑块遮挡 | 敏感区域用黑色方块完全遮盖 | 最高安全性，彻底隐藏 |
| 高斯模糊 | 敏感区域模糊处理，隐约可见轮廓 | 需要保留区域存在感时使用 |
| 星号*掩码 | 文字替换为星号（如 138****6789） | 保留部分信息（如首尾数字）时使用 |

## 操作流程

### PDF 打码

1. 在左侧面板勾选需要处理的敏感信息类型（默认全选）
2. 如需添加自定义关键词，在文本框中输入（一行一个）
3. 切换到「📄 PDF批量打码」标签页
4. 点击「📥 导入PDF」或拖拽 PDF 文件到列表
5. 点击列表中某个文件 → 点击「预览打码效果」查看效果
6. 选择打码模式（黑块/模糊/星号）
7. 点击「📁 选择」设置输出目录（默认输出到桌面「打码输出」文件夹）
8. 点击「🚀 批量导出打码PDF」开始处理
9. 等待进度条完成，弹出完成提示

### 图片打码

1. 同上配置敏感规则
2. 切换到「🖼️ 图片批量打码」标签页
3. 导入图片文件（JPG/PNG/BMP/TIFF）
4. 预览 → 选择模式 → 设置输出 → 批量导出

## 输出说明

- 处理后的 PDF 文件保留原始排版，文件名添加「_打码」后缀
- 处理后的图片保留原始尺寸和画质（JPEG 质量 95%）
- 输出文件保存到指定的输出目录

## 注意事项

1. **检测精度**：住址信息的正则匹配可能存在误判和漏判，建议配合自定义关键词使用
2. **扫描PDF**：对于纯扫描图片型 PDF，程序会先将页面转换为图像再进行打码处理
3. **OCR 依赖**：图片中的文字检测需要系统安装 Tesseract OCR（可选，未安装时使用形态学文字区域检测作为回退方案）
4. **性能**：批量处理大量大文件时建议耐心等待，进度条会显示处理进度
5. **备份**：打码操作不可逆，建议处理前备份原始文件

## 技术信息

- 开发语言：Python 3.14
- GUI 框架：PySide6（Qt for Python）
- PDF 处理：PyMuPDF
- 图片处理：OpenCV + Pillow
- 打包工具：PyInstaller（单文件 EXE）
- 程序大小：约 117 MB（含完整运行环境）

## 常见问题

**Q: 为什么图片打码没有检测到敏感信息？**
A: 请确保已安装 Tesseract OCR 及中文语言包。未安装时将使用形态学文字检测，精度有限。

**Q: PDF 打码后文字层还在吗？**
A: 黑块模式保留 PDF 文字层（使用原生 redact）；模糊/星号模式会将页面转为图像处理，文字层会丢失。

**Q: 能否只打码部分页面？**
A: 当前版本对 PDF 所有页面进行处理，不支持选择性跳页。

**Q: 程序报错怎么办？**
A: 请确认输入文件未损坏、输出目录有写入权限。如问题持续，请检查文件格式是否兼容。
